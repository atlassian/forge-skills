# Celebrate — Forge Guru is live

Read right after `build` succeeds. This is the payoff. Keep it warm, visual, and concrete —
no further questions, no gates.

## Report template

Adapt the wording naturally; keep the structure:

> 🎉 **Forge Guru is live on `<site-host>`.**
>
> **Find your agent:** `<direct link into Rovo on the test site>`
>
> **Try asking it:**
> - What's the difference between a Forge module and a function?
> - How do I add a scheduled trigger to my app?
> - What scopes do I need to read a Confluence page?
> - Show me a minimal manifest for a Jira issue panel.
>
> If you want to see the code, it's at `<app path>`.

## Guidance

- Link the exact test site and, when possible, deep-link into Rovo on that site.
- Pick 3–4 example prompts from the list above, or substitute equivalents if the user
  mentioned a specific Forge area during setup.
- Mention the local app directory once so a curious user can poke at the code; do not
  walk through files unless asked.
- If the install succeeded but the user has not asked Guru a question yet, invite them to
  try one of the example prompts. Record whether a live Guru answer was observed — a
  successful install alone is not evidence that Guru responded.

Move to [`next-steps`](next-steps.md) after the celebration — do not wait for the user
to say "done".
